# Projetos CSS

Repositório com projetos práticos de CSS3, desenvolvidos durante um curso em vídeo. Cada pasta é um site completo (HTML + CSS), geralmente reproduzido a partir de um layout de referência, com foco em consolidar os conceitos vistos nas aulas de CSS.

## Tecnologias

- HTML5
- CSS3

## Projetos

| Projeto | Descrição | Conceitos praticados |
|---|---|---|
| [`Projeto_00(Introdutorio)`](./Projeto_00(Introdutorio)) | Página de detalhes de produto (iPhone 13) | Primeiro projeto de estilização, aplicação inicial de CSS sobre HTML |
| [`Projeto_01(Noticiais)`](./Projeto_01(Noticiais)) | Portal de notícias ("City News") | Layout de múltiplas colunas, organização de conteúdo editorial |
| [`Projeto_02(Chale)`](./Projeto_02(Chale)) | Site institucional de um chalé/pousada | Layout de página única, imagens de fundo, estilização de seções |
| [`Projeto_03(Museu)`](./Projeto_03(Museu)) | Site do Museu Nacional | Layout de página única com galeria de imagens, uso de `normalize.css` |
| [`Projeto_Anna-bella`](./Projeto_Anna-bella) | Site pessoal/institucional ("Anna Bella") | Site com múltiplas páginas (Home, Biografia, Campanhas, Contato) |
| [`Projeto_Techblog`](./Projeto_Techblog) | Blog de tecnologia ("TecBlog") | Site com múltiplas páginas por categoria (Celulares, Eletrônicos, Info, Jogos) |

Cada projeto tem seu próprio `README.md` com mais detalhes.

## Como visualizar

Clone o repositório:

```bash
git clone https://github.com/oIcaro/Projetos--CSS.git
```

Em seguida, abra o arquivo `index.html` da pasta do projeto desejado diretamente no navegador.
