# Projeto 00 - Introdutório

Página de detalhes de produto, reproduzindo o layout de uma página de e-commerce (Apple iPhone 13). Primeiro projeto prático de CSS do curso, com foco na transição de HTML puro para HTML estilizado.

## Conceitos praticados

- Vínculo de folha de estilo externa (`css/style.css`)
- Estilização de imagem de produto
- Estruturação visual de título, especificações e preço
- Comparação entre o arquivo original (fornecido como referência) e a versão estilizada

## Estrutura de arquivos

```
Projeto_00(Introdutorio)/
├── index.html
├── css/
│   └── style.css
├── img/
│   └── iphone.png
└── arquivo_original/       # versão de referência fornecida antes da estilização
    ├── index.html
    └── img/
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
