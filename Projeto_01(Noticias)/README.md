# Projeto 01 - Noticiais

Portal de notícias ("City News"), com seções de entrevistas, últimas notícias e reportagens internacionais. Projeto focado em layout editorial, com múltiplas imagens e blocos de conteúdo organizados em colunas.

## Conceitos praticados

- Organização de conteúdo em seções (Entrevistas, News, Mundo)
- Layout de colunas para blocos de notícia
- Estilização de imagens de destaque e elementos decorativos (divisores, marcadores)
- Uso de imagens de fundo

## Estrutura de arquivos

```
Projeto_01(Noticiais)/
├── index.html
├── css/
│   └── style.css
└── img/
    ├── logo.png
    ├── cidade.jpg
    ├── doutor.jpg
    ├── mundo.jpg
    ├── taxi.jpg
    ├── tecnologia.jpg
    └── (imagens decorativas: fundo, divisor, marcador, detalhe-topo)
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
