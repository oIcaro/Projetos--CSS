# Projeto 03 - Museu

Site institucional do "Museu Nacional", em página única, com galeria de imagens, depoimentos de visitantes e rodapé informativo.

## Conceitos praticados

- Uso de `normalize.css` para padronizar estilos entre navegadores
- Layout de página única com múltiplas seções (galeria, depoimentos, rodapé)
- Imagens de fundo para seções específicas (foto de destaque, rodapé)
- Organização de galeria com múltiplas imagens numeradas

## Estrutura de arquivos

```
Projeto_03(Museu)/
├── index.html
├── css/
│   ├── style.css
│   └── normalize.css
├── img/
│   ├── logo.png
│   ├── museu.png
│   ├── imagem1.jpg ... imagem6.jpg
│   └── (imagens de fundo e depoimento)
├── js/
└── Arquivo Original/       # versão de referência fornecida antes da estilização
    └── Museu Nacional/
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
