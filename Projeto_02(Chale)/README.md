# Projeto 02 - Chalé

Site institucional de um chalé/pousada, em página única, apresentando apartamentos, restaurante, piscina e depoimentos de hóspedes.

## Conceitos praticados

- Layout de página única (single page) com múltiplas seções
- Imagens de fundo compostas (área principal, área lateral, container, rodapé)
- Estilização de elementos decorativos (ornamentos, linhas divisórias)
- Organização de galeria de fotos (apartamento, piscina, restaurante)

## Estrutura de arquivos

```
Projeto_02(Chale)/
├── index.html
├── css/
│   └── style.css
├── img/

└── Arquivo_Original/       # versão de referência fornecida antes da estilização

```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
