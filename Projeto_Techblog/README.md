# Projeto Techblog

Blog de tecnologia ("TecBlog"), com múltiplas páginas organizadas por categoria de conteúdo.

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Página inicial (Home) |
| `celulares.html` | Categoria: Celulares |
| `eletronicos.html` | Categoria: Eletrônicos |
| `info.html` | Página institucional / informações |
| `jogos.html` | Categoria: Jogos |

## Conceitos praticados

- Navegação entre múltiplas páginas por categoria
- Reaproveitamento de uma folha de estilo (`css/style.css`) em todas as páginas
- Organização de conteúdo em formato de blog/portal
- Uso de imagens ilustrativas por categoria

## Estrutura de arquivos

```
Projeto_Techblog/
├── index.html
├── celulares.html
├── eletronicos.html
├── info.html
├── jogos.html
├── css/
│   └── style.css
└── img/
    └── imagem1.jpg ... imagem5.jpg
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
