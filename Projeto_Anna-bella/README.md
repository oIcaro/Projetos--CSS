# Projeto Anna Bella

Site pessoal/institucional de várias páginas ("Anna Bella"), com seções de biografia, campanhas e contato. Projeto focado em navegação entre páginas mantendo uma identidade visual consistente.

## Páginas

| Arquivo | Conteúdo |
|---|---|
| `index.html` | Página inicial (Home) |
| `biografia.html` | Biografia |
| `campanhas.html` | Campanhas |
| `contato.html` | Contato |

## Conceitos praticados

- Navegação entre múltiplas páginas com identidade visual unificada
- Reaproveitamento de uma folha de estilo (`css/style.css`) em todas as páginas
- Organização de galeria de fotos
- Uso de imagem de fundo e imagem de capa

## Estrutura de arquivos

```
Projeto_Anna-bella/
├── index.html
├── biografia.html
├── campanhas.html
├── contato.html
├── css/
│   └── style.css
├── img/
│   ├── capa.png
│   ├── fundo.png
│   └── foto1.png, foto2.png, foto3.png
└── Arquivo_Original/       # versão de referência fornecida antes da estilização
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
